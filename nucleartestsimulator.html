Calculation source

Blast uses range_from_psi_hob(yieldKt, psi, hobFt). NUKEMAP returns this distance in feet, which is converted directly to meters before drawing.

Fireball uses miles. Prompt-radiation and thermal distances are handled as miles; for airbursts their slant ranges are projected to ground range using the burst height before plotting.

NUKEMAP's older effects library is not a formal stable public API, so this page checks the functions at runtime and reports an error instead of silently substituting a different physics model.
